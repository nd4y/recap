# grafana

Два дашборда для импорта: Dashboards → New → Import → загрузить файл, в поле Datasource выбрать
Prometheus-совместимый источник (переменная `DS_PROMETHEUS`).

## recap.json — конвейер

- **Конвейер** — реестр (done / failed / skipped / в работе), последний тик workflow, outbox,
  файлов в час по типу, секунд ASR и LLM на секунду аудио, давность последней записи.
- **recap-asr** — доступность сервиса, запросы в обработке, модели в VRAM, доля опознанного владельца,
  аудио и запросы за сутки, время GPU по стадиям, p50/p95 длительности запроса.
- **n8n** — короткая сводка по движку (экзекьюшены, длительность, память, версия).

Панели с таймингами пусты, пока в реестре нет файлов с полями `duration` / `asr_seconds` / `llm_seconds`.

## n8n.json — движок

Отдельный дашборд по n8n как по сервису, без привязки к recap. Переменные: `job` (скрейп-job n8n,
по умолчанию все), `container` (имя контейнера для ряда cAdvisor, по умолчанию `n8n`).

- **Обзор** — версия, активные workflow, роль инстанса, аптайм, экзекьюшенов и неуспешных за сутки.
- **Экзекьюшены** — в час по workflow и по статусу, p50/p95 длительности (лог-шкала: пустой тик — доли
  секунды, тик с батчем — минуты), средняя длительность по workflow, выполненные ноды, кэш выражений.
- **Процесс node.js** — память (RSS, heap, external), CPU user/system, лаг event loop, доля времени в GC,
  хендлы и дескрипторы.
- **Контейнер (cAdvisor)** — память и лимит, CPU, сеть, время старта, OOM-события, память от лимита.
  Ряд пуст, если cAdvisor не скрейпится; метки `name` у контейнерных серий — стандартные для cAdvisor.

Ожидаемые job'ы в скрейпе: `n8n`, `recap-exporter`, `recap-asr` (см. DEPLOY.md, раздел «Метрики»).
